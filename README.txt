----------------------------------------------------------
PROJECT OVERVIEW
----------------------------------------------------------

CampusFlow is a web-based platform designed to simplify the
management of college club events and the On-Duty (OD)
approval process. It provides a centralized system where
students, club coordinators, faculty mentors, HODs, and
administrators can efficiently manage events, registrations,
approvals, attendance, certificates, and notifications.

The project aims to replace manual paperwork with a secure,
transparent, and digital workflow.

----------------------------------------------------------
OBJECTIVES
----------------------------------------------------------

• Digitalize the club event management process.
• Simplify student event registrations.
• Automate the OD approval workflow.
• Reduce paperwork and manual verification.
• Improve communication between students and faculty.
• Maintain event participation records.
• Generate reports and analytics.

----------------------------------------------------------
USER ROLES
----------------------------------------------------------

1. Student
   • Register/Login
   • View available clubs
   • Browse upcoming events
   • Register for events
   • Apply for OD
   • Track approval status
   • Download certificates
   • Receive notifications

2. Club Coordinator
   • Create/Edit/Delete events
   • Approve registrations
   • Mark attendance
   • Upload event photos
   • Generate certificates
   • View participation reports

3. Faculty Mentor
   • Review club events
   • Recommend OD requests
   • View student participation

4. Head of Department (HOD)
   • Approve/Reject OD requests
   • View department reports
   • Track student activity

5. Administrator
   • Manage users
   • Manage departments
   • Manage clubs
   • Manage events
   • Generate reports
   • Dashboard analytics
